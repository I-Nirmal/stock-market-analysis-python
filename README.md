# Stock Market Analysis with Yahoo Finance

## Overview

This project automates the extraction, cleaning, and analysis of stock market data from Yahoo Finance. It collects real-time stock prices, historical market data, and key financial metrics for active stocks and prepares the data for further analysis and reporting.

## Features

* Extracts stock market data from Yahoo Finance
* Collects real-time prices and historical stock data
* Retrieves key financial metrics
* Cleans and transforms raw data using Pandas
* Implements Object-Oriented Programming (OOP) for better code organization
* Generates structured datasets for analysis

## Tech Stack

* Python
* Pandas
* NumPy
* Requests
* Yahoo Finance API / Data Source

## Workflow

1. Fetch stock market data from Yahoo Finance.
2. Extract real-time prices and financial metrics.
3. Clean and preprocess the data.
4. Store the processed data for analysis.
5. Generate insights and reports.
